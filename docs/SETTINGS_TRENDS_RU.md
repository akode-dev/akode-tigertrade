# _Akode: Trends — Настройки индикатора

Индикатор рисует горизонтальные уровни поддержки и сопротивления, а также наклонные трендовые линии. Внутри — до пяти независимых профилей, каждый со своим таймфреймом и стилем. Трендлайны строятся по объединённым уровням всех профилей.

## Профили (до 5 штук)

Каждый профиль ищет уровни отдельно. Можно включить один профиль на часовике, второй — на 15-минутках, и т.д.

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Enabled | Профиль 1 вкл., остальные выкл. | Включить или выключить профиль. |
| Include in trend lines | Да | Учитывать уровни этого профиля при построении трендлайнов. |
| Interval | Any Time Frame | На каком таймфрейме искать уровни. «Any» — текущий таймфрейм графика. |
| Value | 1 | Множитель интервала (например, Minute + 5 = пятиминутка). |
| Candles before | 2 | Сколько свечей слева от пивота нужно для его подтверждения. |
| Candles after | 2 | Сколько свечей справа от пивота нужно для его подтверждения. |
| Max High lines to show | 5 | Сколько уровней сопротивления показывать от этого профиля. |
| Max Low lines to show | 5 | Сколько уровней поддержки показывать от этого профиля. |
| Use candle body instead of wicks | Нет | Определять пивоты по телу свечи (open/close), а не по теням (high/low). |
| Show broken lines | Нет | Показывать уровни, которые цена закрытия уже пробила. |
| Max High lines (broken) | 2 | Сколько пробитых уровней сопротивления показывать. |
| Max Low lines (broken) | 2 | Сколько пробитых уровней поддержки показывать. |
| Show tested lines | Да | Показывать уровни, которые тень проколола, но цена закрытия не пробила. |
| Max High lines (tested) | 1 | Сколько протестированных уровней сопротивления показывать. |
| Max Low lines (tested) | 1 | Сколько протестированных уровней поддержки показывать. |
| High levels | Цветная линия | Стиль и цвет линий сопротивления. |
| Low levels | Цветная линия | Стиль и цвет линий поддержки. |

## Общие фильтры уровней

После того как каждый профиль нашёл свои уровни, к ним применяются общие фильтры.

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Max total High levels | 7 | Максимум уровней сопротивления на графике (суммарно по всем профилям). Самые свежие остаются. 0 = без ограничений. |
| Max total Low levels | 7 | Максимум уровней поддержки. |
| Time filter (minutes) | 0 | Скрывать уровни старше N минут. 0 = показывать все. |
| Level merge (ticks) | 50 | Если два уровня ближе N тиков — оставить более значимый. 0 = не объединять. |
| Apply filters to trend lines | Да | Применять эти фильтры и к входным данным трендлайнов. |

## Надписи расстояния (Distance labels)

Рядом с каждым видимым уровнем показывается, сколько процентов до него от текущей цены (например, `+1.5%`). Если дальше есть ещё один уровень — рядом отображается расстояние до него: `▲0.8%` для сопротивления, `▼0.8%` для поддержки.

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Show distance % labels | Да | Показывать процентные надписи на графике. |
| Distance % decimals | 1 | Знаков после запятой в процентах (1–4). |
| Distance label font size | 9 | Размер шрифта основной надписи (`+1.5%`). |
| Distance label bold | Нет | Жирный шрифт для основной надписи. |
| Gap label font size | 9 | Размер шрифта надписи расстояния до следующего уровня (`▲0.8%`). |
| Gap label bold | Нет | Жирный шрифт для надписи следующего уровня. |

## Круглые уровни

Уровни, которые совпадают с «круглыми» ценами (например, 100, 500, 10000), выделяются отдельным стилем.

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Highlight round levels | Нет | Включить выделение круглых уровней. |
| Round step | 0 | Шаг круглого числа. 0 = автоматически (тик × 100). |
| Round tolerance (ticks) | 0 | Допуск: уровни в пределах N тиков от круглого числа тоже считаются круглыми. |
| Round High levels | Золотая линия | Стиль для круглых уровней сопротивления. |
| Round Low levels | Золотая линия | Стиль для круглых уровней поддержки. |

## Стили протестированных уровней

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Tested High levels | Зелёный, пунктир | Стиль линии, если тень проколола уровень сопротивления, но close удержался. |
| Tested Low levels | Красный, пунктир | Стиль линии, если тень проколола уровень поддержки, но close удержался. |

## Точки подтверждения (Confirmation dots)

Помогают быстро находить уровни, к которым цена уже возвращалась. На каждом подтверждённом уровне рисуются две точки с номерами:

- **Точка 1** — свеча, на которой уровень появился (пивот).
- **Точка 2** — свеча, на которой цена подошла к уровню ближе всего, но не пробила его.

Когда после точки 2 проходит достаточно свечей, она меняет цвет (по умолчанию на зелёный). Это сигнал: уровень проверен временем и работает.

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Show confirmation dots | Нет | Показывать точки подтверждения. |
| Tolerance (x0.1%) | 5 | Насколько близко цена должна подойти к уровню. Значение 5 = 0.5%, 10 = 1.0%. Цена не должна пересечь уровень даже тенью — иначе точка не считается. |
| Min bars between touches | 10 | Минимум свечей между точкой 1 и точкой 2. Защищает от ложных срабатываний на соседних барах. |
| Timeframe (minutes, 0=chart) | 0 | На каком таймфрейме считать точки (в минутах). 0 = текущий таймфрейм графика. Задайте значение (например, 1), чтобы точки не прыгали при переключении на секундный график. |
| Dot size | 6 | Размер точки в пикселях. |
| Dot color | Голубой | Цвет обеих точек (пока точка 2 «свежая»). |
| Mature after bars | 5 | Через сколько свечей после точки 2 она «созреет» и поменяет цвет. |
| Mature dot color | Зелёный | Цвет зрелой точки 2 — визуальный сигнал, что уровень подтверждён. |

### Как работает поиск точки 2

1. Берутся все видимые горизонтальные уровни, которые ещё не пробиты (close не прошёл за уровень).
2. Для каждого уровня сканируются свечи после пивота (с учётом минимального расстояния).
3. Ищется свеча, чья тень подошла к уровню ближе всего, но не пересекла его:
   - Для **сопротивления**: high свечи в зоне от `цена − допуск` до `цена`, но не выше уровня.
   - Для **поддержки**: low свечи в зоне от `цена` до `цена + допуск`, но не ниже уровня.
4. Из всех подходящих свечей выбирается та, что подошла **ближе всего** к уровню.
5. Если цена закрытия в какой-то момент пробивает уровень — уровень считается сломанным, точки не рисуются.

## Трендовые линии

Наклонные линии, построенные по объединённым уровням всех профилей. Показывают глобальное направление поддержки и сопротивления.

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Show trend lines | Да | Показать или скрыть трендлайны. |
| Max High trend lines | 4 | Сколько верхних (сопротивление) трендлайнов показывать. |
| Max Low trend lines | 4 | Сколько нижних (поддержка) трендлайнов показывать. |
| Tolerance in ticks | 100 | Допуск касания: насколько далеко от трендлайна ещё считается «касанием». |
| Min High touches | 2 | Минимум касаний для построения верхнего трендлайна. |
| Min Low touches | 2 | Минимум касаний для построения нижнего трендлайна. |
| Left padding bars | 50 | Продлить трендлайн влево от первого касания (баров). |
| Right padding bars | 500 | Продлить трендлайн вправо за последнюю свечу (баров). |
| High: only down slope | Да | Верхние трендлайны только с нисходящим наклоном. |
| Low: only up slope | Да | Нижние трендлайны только с восходящим наклоном. |
| Trendline algorithm | RANSAC | Алгоритм подбора: Classic Touches, Weighted Regression, RANSAC, Hough Transform. |
| Allowed past crossing bars | 5 | Допускать пересечение верхнего и нижнего трендлайнов только в последних N барах. |
| Hide broken trend lines | Да | Скрывать трендлайны, пробитые телом свечи. |
| Break bars | 5 | Сколько баров подряд тело свечи должно быть за трендлайном, чтобы считать его пробитым. |
| Break tolerance in ticks | 5 | Допуск за пределами трендлайна для фиксации пробоя (тиков). |
| Memory (bars) | 0 | Зафиксировать трендлайны на N баров — не пересчитывать. 0 = выключено. |
| Memory (minutes) | 0 | Зафиксировать трендлайны на N минут. 0 = выключено. |
| Trend merge (ticks) | 100 | Объединять похожие трендлайны в пределах N тиков. 0 = не объединять. |
| High trends | Серая линия | Стиль верхних трендовых линий. |
| Low trends | Серая линия | Стиль нижних трендовых линий. |

## Приоритет стилей уровней

Если уровень попадает в несколько категорий, применяется стиль с наивысшим приоритетом:

1. **Round** (круглый уровень) — наивысший
2. **Tested** (тень проколола, close удержался) — средний
3. **Broken** (close пробил) — точечная линия
4. **Active** (обычный) — базовый стиль профиля

## Три состояния уровня

| Состояние | Что произошло (сопротивление) | Что произошло (поддержка) | Стиль линии |
| --- | --- | --- | --- |
| Active | Цена ни тенью, ни close не дошла до уровня | То же | Сплошная |
| Tested | Тень проколола уровень, но close остался ниже | Тень проколола, но close остался выше | Пунктир |
| Broken | Close закрылся выше уровня | Close закрылся ниже уровня | Точечная |
