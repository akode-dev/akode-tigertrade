# _Akode: Trends - Настройки индикатора

Мультипрофильный индикатор уровней поддержки/сопротивления с трендовыми линиями.

По сути — пять независимых экземпляров `AkodeLevelsIndicator`, объединённых в один индикатор с общим движком трендовых линий. Каждый профиль работает автономно (свой таймфрейм, настройки пивотов, лимиты, стили), а алгоритм трендлайнов использует объединённые уровни для построения диагональных линий поддержки/сопротивления.

## Настройки профиля (для каждого из 5 профилей)

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Enabled | Профиль 1: true, остальные: false | Включить/выключить профиль. |
| Include in trend lines | true | Включить уровни этого профиля в расчёт трендлайнов. |
| Interval | Any Time Frame | Таймфрейм для определения пивотов. |
| Value | 1 | Множитель интервала. |
| Candles before | 2 | Баров слева для подтверждения пивота. |
| Candles after | 2 | Баров справа для подтверждения пивота. |
| Max High lines to show | 5 | Макс. активных уровней сопротивления для профиля. |
| Max Low lines to show | 5 | Макс. активных уровней поддержки для профиля. |
| Use candle body instead of wicks | false | Использовать тело свечи (open/close) вместо фитилей (high/low) для пивотов. |
| Show broken lines | false | Показывать уровни, где close прошёл через уровень. |
| Max High lines (broken) | 2 | Макс. сломанных уровней сопротивления для профиля. |
| Max Low lines (broken) | 2 | Макс. сломанных уровней поддержки для профиля. |
| Show tested lines | true | Показывать уровни, где фитиль проколол, но close остался. |
| Max High lines (tested) | 1 | Макс. протестированных уровней сопротивления. |
| Max Low lines (tested) | 1 | Макс. протестированных уровней поддержки. |
| High levels | Цветная линия | Стиль/цвет уровней сопротивления. |
| Low levels | Цветная линия | Стиль/цвет уровней поддержки. |

## Фильтры уровней (глобальные)

Применяются ко всем профилям после их индивидуальной фильтрации.

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Max total High levels | 7 | Макс. общее количество уровней сопротивления. 0 = без лимита. |
| Max total Low levels | 7 | Макс. общее количество уровней поддержки. 0 = без лимита. |
| Time filter (minutes) | 0 | Показывать только уровни, чьи пивоты были за последние N минут. 0 = выключено. |
| Level merge (ticks) | 50 | Объединять уровни в пределах N тиков друг от друга. 0 = выключено. |
| Apply filters to trend lines | true | Применять глобальные фильтры уровней к входным данным трендлайнов. |
| Show distance % labels | true | Показывать процент расстояния до ближайших уровней на графике. |

## Трендовые линии

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Show trend lines | true | Показывать/скрывать трендлайны. |
| Max High trend lines | 4 | Макс. верхних (сопротивление) трендлайнов. |
| Max Low trend lines | 4 | Макс. нижних (поддержка) трендлайнов. |
| Tolerance in ticks | 100 | Допуск касания при оценке трендлайнов. |
| Min High touches | 2 | Минимум касаний для верхних трендлайнов. |
| Min Low touches | 2 | Минимум касаний для нижних трендлайнов. |
| Left padding bars | 50 | Продлить трендлайн влево от первого касания. |
| Right padding bars | 500 | Продлить трендлайн вправо в пустую область графика. |
| High: only down slope | true | Верхние трендлайны только с нисходящим наклоном. |
| Low: only up slope | true | Нижние трендлайны только с восходящим наклоном. |
| Trendline algorithm | RANSAC | Алгоритм: Classic Touches, Weighted Regression, RANSAC, Hough Transform. |
| Allowed past crossing bars | 5 | Допускать пересечения верхних/нижних трендлайнов только в последних N барах. |
| Hide broken trend lines | true | Скрывать трендлайны, пробитые телом свечи. |
| Break bars | 5 | Баров после первого якоря для подтверждения пробоя трендлайна. |
| Break tolerance in ticks | 5 | Допуск в тиках за пределами трендлайна для фиксации пробоя. |
| Memory (bars) | 0 | Зафиксировать трендлайны на N новых баров. 0 = выключено. |
| Memory (minutes) | 0 | Зафиксировать трендлайны на N минут. 0 = выключено. |
| Trend merge (ticks) | 100 | Объединять похожие трендлайны в пределах N тиков. 0 = выключено. |

## Отображение трендлайнов

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| High trends | Серая линия | Стиль/цвет верхних трендовых лучей. |
| Low trends | Серая линия | Стиль/цвет нижних трендовых лучей. |

## Приоритет стилей уровней

1. **Round** (круглый) - наивысший приоритет
2. **Tested** (закол) - средний приоритет
3. **Broken** (сломанный) - точечный стиль
4. **Active** (обычный) - базовый стиль профиля

## Три состояния уровня

| Состояние | Условие (сопротивление) | Условие (поддержка) | Стиль |
| --- | --- | --- | --- |
| Active | Ни фитиль, ни close не прошли | Ни фитиль, ни close не прошли | Solid |
| Tested (закол) | High > уровень, но close <= уровень | Low < уровень, но close >= уровень | Dash |
| Broken | Close > уровень | Close < уровень | Dot |
