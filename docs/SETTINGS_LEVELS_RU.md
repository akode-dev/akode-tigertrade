# _Akode: Levels — Настройки индикатора

Индикатор рисует горизонтальные уровни поддержки и сопротивления. Находит локальные максимумы и минимумы (пивоты) и проводит через них линии. Поддерживает агрегацию по таймфреймам, отслеживает пробитые и протестированные уровни.

## Таймфрейм

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Interval | Any Time Frame | На каком таймфрейме искать уровни. «Any» — текущий таймфрейм графика. |
| Value | 1 | Множитель интервала (например, Minute + 5 = пятиминутка). |

## Настройки пивотов

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Candles before | 2 | Сколько свечей слева от пивота нужно для подтверждения. |
| Candles after | 2 | Сколько свечей справа от пивота нужно для подтверждения. |
| Max High lines to show | 15 | Сколько уровней сопротивления показывать. |
| Max Low lines to show | 15 | Сколько уровней поддержки показывать. |

## Пробитые уровни (Broken)

Уровень считается **пробитым**, если цена закрытия прошла через него.

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Show broken lines | Да | Показывать пробитые уровни (точечная линия). |
| Max High lines (broken) | 2 | Сколько пробитых уровней сопротивления показывать. |
| Max Low lines (broken) | 2 | Сколько пробитых уровней поддержки показывать. |

## Протестированные уровни (Tested)

Уровень считается **протестированным**, если тень свечи проколола уровень, но цена закрытия осталась по правильную сторону.

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Show tested lines | Да | Показывать протестированные уровни. |
| Max High lines (tested) | 1 | Сколько протестированных уровней сопротивления показывать. |
| Max Low lines (tested) | 1 | Сколько протестированных уровней поддержки показывать. |
| Tested High levels | Зелёный, пунктир | Стиль для протестированных уровней сопротивления. |
| Tested Low levels | Красный, пунктир | Стиль для протестированных уровней поддержки. |

## Отображение

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| High levels | Зелёная линия | Стиль и цвет линий сопротивления. |
| Low levels | Красная линия | Стиль и цвет линий поддержки. |
| Show distance % labels | Нет | Показывать расстояние до ближайших уровней в процентах на графике. |

## Круглые уровни

Уровни, совпадающие с «круглыми» ценами (например, 100, 500, 10000), выделяются отдельным стилем.

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Highlight round levels | Нет | Включить выделение круглых уровней. |
| Round step | 0 | Шаг круглого числа. 0 = автоматически (тик × 100). |
| Round tolerance (ticks) | 0 | Допуск: уровни в пределах N тиков от круглого числа тоже считаются круглыми. |
| Round High levels | Золотая линия | Стиль для круглых уровней сопротивления. |
| Round Low levels | Золотая линия | Стиль для круглых уровней поддержки. |

## Приоритет стилей

Если уровень попадает в несколько категорий, применяется стиль с наивысшим приоритетом:

1. **Round** (круглый уровень) — наивысший
2. **Tested** (тень проколола, close удержался) — средний
3. **Broken** (close пробил) — точечная линия
4. **Active** (обычный) — базовый стиль
