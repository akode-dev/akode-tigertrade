# _Akode: Levels - Настройки индикатора

Индикатор горизонтальных уровней поддержки и сопротивления на основе пивот-точек.

Определяет пивот-хай и пивот-лоу, рисует горизонтальные уровни. Поддерживает агрегацию по таймфреймам, отслеживает сломанные и протестированные (закол) уровни.

## Период

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Interval | Any Time Frame | Интервал агрегации для определения пивотов. |
| Value | 1 | Множитель выбранного интервала. |

## Настройки пивотов

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Candles before | 2 | Количество баров слева для подтверждения пивота. |
| Candles after | 2 | Количество баров справа для подтверждения пивота. |
| Max High lines to show | 15 | Максимальное количество активных уровней сопротивления. |
| Max Low lines to show | 15 | Максимальное количество активных уровней поддержки. |

## Сломанные линии (Broken lines)

Уровень считается **сломанным**, если цена закрытия (close) прошла через него.

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Show broken lines | true | Показывать сломанные уровни (точечный стиль). |
| Max High lines (broken) | 2 | Максимум сломанных уровней сопротивления. |
| Max Low lines (broken) | 2 | Максимум сломанных уровней поддержки. |

## Протестированные линии (Tested lines)

Уровень считается **протестированным (закол)**, если фитиль свечи проколол уровень, но цена закрытия осталась по правильную сторону.

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Show tested lines | true | Показывать протестированные уровни. |
| Max High lines (tested) | 1 | Максимум протестированных уровней сопротивления. |
| Max Low lines (tested) | 1 | Максимум протестированных уровней поддержки. |
| Tested High levels | Зелёный, dash | Стиль линии для протестированных уровней сопротивления. |
| Tested Low levels | Красный, dash | Стиль линии для протестированных уровней поддержки. |

## Отображение (Display)

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| High levels | Зелёная линия | Стиль/цвет для уровней сопротивления. |
| Low levels | Красная линия | Стиль/цвет для уровней поддержки. |
| Show distance % labels | false | Показывать процент расстояния до ближайших видимых уровней на графике. |

## Круглые уровни (Round levels)

Выделяет уровни, попадающие на "круглые" ценовые числа, отдельным стилем.

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| Highlight round levels | false | Включить выделение круглых уровней. |
| Round step | 0 | Шаг круглого числа. 0 = авто (размер тика x 100). |
| Round tolerance (ticks) | 0 | Допуск в тиках: уровни рядом с круглым числом считаются круглыми. |
| Round High levels | Золотая линия (ширина 2) | Стиль для круглых уровней сопротивления. |
| Round Low levels | Золотая линия (ширина 2) | Стиль для круглых уровней поддержки. |

## Приоритет стилей

Если уровень попадает под несколько категорий, применяется стиль с наивысшим приоритетом:

1. **Round** (круглый) - наивысший приоритет
2. **Tested** (закол) - средний приоритет
3. **Broken** (сломанный) - точечный стиль
4. **Active** (обычный) - базовый стиль
